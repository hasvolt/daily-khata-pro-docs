## Welcome to Rozfiber Documentation

Welcome to the official documentation portal for **Rozfiber applications and tools**.

This portal brings product documentation together in one place. Whether you are learning to use an application, exploring its features, configuring your account or troubleshooting a problem, start with the documentation for the relevant product.

## Explore Our Applications

### Daily Khata Pro

Daily Khata Pro documentation covers financial records, income and expenses, calculators, reports, privacy, backup and other documented features.

[Open Daily Khata Pro Documentation →](/guide/)

### Staff Manager

Staff Manager documentation covers business setup, staff profiles, attendance, work records, wage calculations, payments, reports, team permissions and technical information.

[Open Staff Manager Documentation →](/staff-manager/)

## How to Use This Portal

1. Select the application you want to learn about.
2. Open its getting-started guide if you are new to the application.
3. Browse the relevant chapter for detailed instructions.
4. Check the FAQ and troubleshooting guides if you need help.
5. Review the relevant privacy, backup and security guidance before handling important records.

## About This Documentation

Documentation describes the features and workflows covered by the available guides. Actual functionality may vary by application version. If a feature is not available in your installed version, check the relevant version information rather than assuming it is supported.

## More Applications Coming Soon

As Rozfiber introduces additional applications and tools, their documentation can be added to this portal. Each product should have its own dedicated section so users can find the correct instructions without mixing documentation between applications.
