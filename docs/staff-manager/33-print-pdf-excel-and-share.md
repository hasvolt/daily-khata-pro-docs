# Print, PDF, Excel and share

## Print

**Print** opens your browser's print dialog. The app waits for fonts and images to load before printing. Printouts use black text on a white background whatever theme you use. Report printouts use a landscape page. Text in any language prints as your device displays it.

## PDF

**PDF** downloads an A4 PDF made by the app. The PDF uses a standard Latin font, so letters from other scripts such as Hindi, Urdu or Tamil may not display correctly. If you need those scripts, use **Print** and choose *Save as PDF* in your browser, or use CSV.

## Excel and CSV

**Excel / CSV** downloads a `.csv` file that opens in Excel, Google Sheets and other spreadsheet apps. The file is saved with UTF-8 so non-English text opens correctly in Excel.

## Share

**Share** uses your device's share sheet (for example WhatsApp) to send a text summary. If sharing is not available, the summary is copied to the clipboard instead.

## What each screen offers

| Screen | Print | PDF | CSV | Share |
|---|:-:|:-:|:-:|:-:|
| Reports | Yes | Yes | Yes | Yes |
| Staff history | Yes | Yes | Yes | Yes |
| Salary slip | Yes | Yes | Yes | Yes |
| Payment receipt | Yes | Yes | No | Yes |

## Options

- Reports let you set a custom title, notes, signature lines and whether to include phone numbers.
- Salary slips let you set header and footer notes and choose signatures and photo.
- Amounts follow the privacy mask.

## Tips

- Save a PDF of each month's slips after you settle the month.
- If a print looks blank, wait a moment and try again, or download the PDF.
- Remove sensitive details before sharing documents.
