# Validation and error messages

| Message | Meaning | What to do |
|---|---|---|
| **Email not confirmed** | The sign-up email link has not been used | Open the confirmation email, then sign in again |
| **Cannot modify attendance: Selected date belongs to a locked settlement period** | The month is closed | Ask the Owner to unlock the month if a correction is needed |
| **Cannot record or edit payment: Selected date is inside a closed and locked month** | The month is closed | Same as above |
| **Duplicate Payment Warning** | A payment with the same amount and date already exists for this staff member | Check the existing payment. Confirm only if the new payment is real |
| **Please type "name" exactly to confirm moving to trash** | The staff member has attendance or payment history | Type the name exactly, or choose Archive |
| **Your role cannot invite a role** | Managers cannot invite managers | Ask the Owner |
| **Cannot remove the owner. Transfer ownership first.** | Owners cannot be removed | Transfer ownership, then remove |
| **You do not have permission to remove this member** | Your role is not allowed | Ask the Owner |
| **Only the business owner can change member roles** | Role changes are Owner only | Ask the Owner |
| **Only owner or manager can lock settlement periods** | Your role cannot close a month | Ask the Owner or a Manager |
| **Not a valid Staff Manager backup JSON file** | The file is not a Staff Manager backup | Choose a backup created by the app |
| **CSV must contain a header row and at least one data row** | The import file is empty or has no header | Use the downloaded template |
| **Sync Issue** badge | The last sync failed | Check your internet and tap **Sync Now** |

## Before saving

Check the staff member, date, type and amount. After saving, check the entry in the list.

## If a save seems stuck

Check the list or the staff history before saving again, to avoid entering the same record twice.

## When asking for support

Include the page you were on, what you did, what you expected and what happened. Do not send passwords. Hide names, phone numbers and amounts in screenshots.
