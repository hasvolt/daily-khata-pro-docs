# Basic calculator

Staff Manager has a simple calculator built in. Open it from the calculator icon in the header, the side menu (**Inbuilt Quick Calculator**) or the calculator icon next to amount boxes.

## What it does

- Add, subtract, multiply and divide (`+ − × ÷`)
- Percentage (`%`)
- Decimal point, backspace and clear
- Keyboard support on computers: numbers, operators, `%`, Enter or `=`, Backspace and Escape
- A history of your last 10 calculations, stored in this browser

## Use result

From an amount box, tap **Use Result** to put the answer into that box.

## Advanced calculators

Staff Manager does not include advanced calculators. The **Advanced Calculators** button opens the Daily Khata Pro calculators. If you started from an amount, the value is passed along. The button appears only if the administrator configured the link. See [Daily Khata Pro integration](70-daily-khata-pro-integration.md).
