# Reports and filters

Open **Reports**.

## Report types

| Report | Shows |
|---|---|
| **Attendance Register** | Attendance for the period |
| **Payment Statement** | Payments for the period |
| **Advances Ledger** | Advances, loans and repayments |
| **Pending Dues** | What is owed to or by each staff member |
| **Labour Cost by Site** | Cost grouped by site, shop or project |
| **Work Summary** | Work entries and totals |
| **Full Staff History** | Everything for one staff member |

Reports that show payments are for roles that can view payments.

## Filters

- **Date range:** presets This Month, Last Month, 3 Months, 6 Months, This Year, or a custom start and end date. There is no one-month limit.
- **Staff member:** all staff or one person.
- **Site / project.**

## Report options

- **Custom Report Title**
- **Report Notes**
- **Include Signatures**
- **Include Phone / Contact**

Phone numbers are included only if you select that option.

## Saved presets

Use **Save Preset** to save the current filters and options under a name, and load them again later.

## Output

Print, PDF, CSV (opens in Excel) and share. See [Print, PDF, Excel and share](33-print-pdf-excel-and-share.md).

## Privacy mask

When the privacy mask is on, amounts are hidden in reports. See [Privacy mask](52-privacy-mask.md).

## Performance

Reports are calculated on your device from the records stored there.
