# Install and offline use

Staff Manager is a Progressive Web App (PWA). You can install it like a normal app.

## Install

- **Android or computer (Chrome, Edge):** tap **Install App** if shown, or use the browser menu and choose *Install app* / *Add to Home screen*.
- **iPhone or iPad (Safari):** tap the Share button, then **Add to Home Screen**. The app shows the same steps in an **Install on iPhone / iPad** guide.

## Offline use

After you open the app once with internet, it can open without internet. An **Offline Mode** indicator appears when there is no connection. While offline you can keep working with the data on your device: attendance, work entries, payments and reports.

Changes made offline wait in a queue and sync when you are online again. See [Multi-device, sync and offline](42-multi-device-sync-and-offline.md).

Some features need internet: signing in, joining a business, creating cloud invites, and the online Google Translator.

## Updates

The app updates itself automatically in the background. If something looks outdated after an update, close the app completely and open it again.

## Tips

- Open the app online regularly if you work with a team, so everyone stays in sync.
- Do not clear browser data until the sync badge shows **Synced**.
