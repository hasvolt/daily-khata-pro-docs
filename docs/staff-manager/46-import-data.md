# Import data

You can import a **staff list** from a **CSV** file. Importing attendance and payments is not available.

## Steps

1. Open **Staff** and choose **Import CSV**.
2. Choose **Download Template**. The file `staff_import_template.csv` has the column headings and sample data.
3. Fill in your staff in the template and save it as CSV.
4. Upload the file.
5. Review the preview. The app shows how many rows are valid and how many have problems.
6. Import the valid rows.

## Undo an import

After importing, you can **roll back** the last import. The staff added by that import are removed.

## Tips

- Keep the template headings exactly as they are.
- Try a small file first.
- Download a backup before a large import.

## Who can import

Owner and Manager.
