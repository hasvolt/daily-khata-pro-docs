# Glossary

| Term | Meaning |
|---|---|
| **Advance (Peshgi / Udhar)** | Money given to staff before it is earned |
| **Archive** | Hides a staff member from daily lists but keeps all history |
| **Audit log** | A record of who changed what and when |
| **Business** | One workplace with its own staff and data |
| **Conflict** | Two devices changed the same record before syncing |
| **Custom field** | An extra field you add to staff profiles |
| **Half Day** | Counted as half a day |
| **Ledger** | A staff member's earnings, payments and balance |
| **Local mode** | Using the app without an account |
| **Net Payable** | What is still due after advances, deductions and payments |
| **Offline first** | Works without internet and syncs later |
| **Outstanding advances** | Advances and loans taken minus repayments |
| **Overtime** | Extra hours beyond the normal day |
| **Per Piece / Per Unit** | Pay by quantity of work |
| **Period lock** | Prevents changes to attendance and payments in a closed month |
| **Privacy mask** | Hides amounts on screen |
| **Role** | Owner, Manager, Supervisor, Accountant or Viewer |
| **Settle month** | Review what is due, pay, and close the month |
| **Site / Project** | Where the work is done |
| **Sync** | Sending and receiving changes with the cloud |
| **Trash** | Where deleted items wait for restore |
| **Work type** | A category of work, such as plastering |
