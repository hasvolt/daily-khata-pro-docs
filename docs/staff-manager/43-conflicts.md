# Conflicts

A **conflict** happens when two devices change the same record before they have synced with each other.

## Automatic handling

Changes to different records merge without any action.

## Resolve a conflict

Open the menu and choose **Sync Conflicts**. For each conflict you see your version and the version on the server. Choose:

- **Keep mine**
- **Keep theirs**
- **Merge** (build a combined version)

Each resolution is saved in the [activity log](48-audit-log-and-activity.md).

## Avoid conflicts

- Let each person handle different staff or sites.
- Wait for **Synced** before you start editing.
