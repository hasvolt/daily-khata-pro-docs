# Multi-device, sync and offline

## How it works

1. You change something. It is saved **on your device immediately**.
2. If you are signed in, the change is queued.
3. When you are online, the queue is sent to the cloud.
4. Other devices receive the change.

## Sync status

The header badge shows the status:

| Badge | Meaning |
|---|---|
| **Synced** | Everything is up to date |
| **Syncing** | Changes are being sent or received |
| **Offline** | No internet. Changes are saved on this device |
| **Sync Issue** | The last sync failed |

Tap the badge to see the number of pending changes, the last error and the **Sync Now** button.

## When sync runs

Sync runs when you open the app, when your internet returns, when you return to the app window, and every 3 minutes while the app is open.

## Live updates

While you are online, the app listens for changes from other members and updates your data.

## Using several devices

Sign in with the same account on each device and select the same business. Wait for **Synced** before switching devices.

## Two people editing

Different records merge without any action. If two people change the same record, see [Conflicts](43-conflicts.md).

## Local mode

Without an account, nothing syncs. See [Local mode and upgrade to cloud](04-local-mode-and-upgrade-to-cloud.md).

## Tips

- Open the app online regularly if you work in a team.
- Do not clear browser data until you see **Synced**.
- If you see **Sync Issue**, see [Troubleshooting](62-troubleshooting.md).
