# Work entries, sites and work types

## Work entry

On **Home**, choose **Log Daily Work**.

| Field | Notes |
|---|---|
| **Staff Member** | Required |
| **Date** | Required |
| **Site / Project / Shop** | Choose from your sites |
| **Task / Work Description** | Free text |
| **Work Type** | Choose from your work types |
| **Quantity (Piece Workers)** | Drives earnings for Per Piece / Per Unit staff |
| **Hours Worked** | Used for hourly staff |
| **Attach Work Photo (Optional)** | A photo of the work |
| **Notes** | Materials, measurements, remarks |

Example: a per piece worker who plastered 350 sq ft is recorded with quantity 350. Earnings are 350 multiplied by the rate.

## Sites / Shops

Choose **Manage Sites / Shops** on Home. A site has a name and an optional address or location.

## Work types

Choose **Manage Work Types** on Home. A work type has a name, an optional unit name (for example sq ft, point, bag, kg) and an optional default rate per unit.

## Edit and delete

Edit or delete work entries, sites and work types. Deleted items go to [Trash](44-trash-and-recovery.md).

## Where work appears

Work appears in [Work history](30-work-history.md), the Work Summary report and Labour Cost by Site report. See [Reports and filters](32-reports-and-filters.md).

## Who can use it

Owner, Manager and Supervisor can log work. Others can view.
