# Custom fields

Every business is different. Custom fields let you record extra information on each staff profile.

## Field types

| Type | Use |
|---|---|
| **Text (Single Line)** | Names, numbers with letters, short notes |
| **Number** | Quantities and amounts |
| **Date** | Expiry or issue dates |
| **Dropdown (Options)** | A fixed list. Enter the options separated by commas, for example `Small, Medium, Large, XL` |
| **Yes / No (Checkbox)** | A simple tick |

## Create a field

Open **Staff**, choose **Custom Fields**, then add a field with a **Field Label** and a **Field Type**. The field then appears on staff profiles.

Examples: Uniform Size, Licence Expiry, Helmet Issued, Vehicle Number.

## Edit or delete

You can rename a field or delete it. Deleted custom fields go to [Trash](44-trash-and-recovery.md) and can be restored.

## Scope

Custom fields apply to **staff profiles**. Attendance, work entries and payments have fixed fields, plus a note.

## Who can manage them

Owner and Manager. Others can view the values.
