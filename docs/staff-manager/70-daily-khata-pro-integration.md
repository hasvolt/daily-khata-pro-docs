# Daily Khata Pro integration

Staff Manager and **Daily Khata Pro** are separate Rozfiber apps.

## Open Daily Khata Pro

Use **Open Daily Khata Pro** in the menu, or the **Daily Khata Pro Integration** card on Home.

## Advanced calculators

Staff Manager only has a basic calculator. **Advanced Calculators** opens the Daily Khata Pro calculators and passes the amount you had, if any. The button appears only if the administrator set the link. See [Basic calculator](20-basic-calculator.md).

## Export payments for expense entry

On Home, the **Daily Khata Pro Integration** card has **Export Payouts for Expense Entry**. It downloads a CSV of your payments named `<business>_Expenses_for_DailyKhata`. Use it to enter staff payments as expenses in Daily Khata Pro.

## What is not shared

The two apps do not share accounts, databases or data automatically. You sign in to each one separately, and you move payment totals yourself using the CSV.
