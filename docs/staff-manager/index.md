# Staff Manager Documentation

Welcome to the official documentation for **Staff Manager**.

Staff Manager helps contractors, small business owners and teams organize staff records, attendance, work entries, wages, payments and reports.

Use this documentation to understand the available features, learn how to use them, configure your business and troubleshoot common problems.
